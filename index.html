Architecture

One system, four clients

Exifora as it runs today. Every box is something I designed, built and operate. Dashed lines are the paths a photo takes from a phone to a jury.

Clients share one codebase

Compose Multiplatform ships native Android and iOS; Swift is only 13 files of interop. Web is a separate Next.js app on the same API.

Business rules live server-side

Auth, quotas, payments and jury logic are Go usecases over parameterized SQL. Clients render; they do not decide.

Uploads never block the API

Phones and browsers PUT straight to R2 with short-lived presigned URLs. The API only sees metadata and EXIF.

Recoverable by design

Continuous WAL archiving to R2 and a rehearsed disaster-recovery runbook. Releases are tag-driven to three stores.

Applied AI

What I have shipped with Claude

All of it runs in production inside Exifora on the Anthropic Go SDK. Every call sits behind a subscription tier, a daily quota and a cache, and the whole layer degrades to zero cost when no key is configured.

Vision · Opus tier

AI Photo Coach

A member uploads one photo a day and gets a bilingual read on light, composition and framing, grounded in the frame's real EXIF values.

Vision · Haiku tier

Contest pre-check

Before submitting, a Pro member sees theme fit plus exposure, composition and sharpness scores for the staged photo.

Vision · Batches API

Jury critique at scale

Bulk critiques for a whole contest edition run through the Message Batches API at half the price, with 72-hour presigned image URLs.

Vision · EXIF grounding

Academy grading

Homework for a 30-plus module photography curriculum is judged against written criteria, with instructor feedback that cites the actual aperture, shutter and ISO.

Text · Opus tier

Editorial pipeline

RSS and YouTube feeds become original blog drafts in the product's voice, paced onto fixed publish slots. Press releases follow strict fact-discipline prompts.

Vision · moderation

Safety gates

A Claude moderation gate vets imported imagery, a browser-side TensorFlow.js NSFW model screens uploads, and dHash catches near-duplicate reposts.

Text · 10 locales

Photo of the Week

One English commentary is written on the deep tier and translated into all ten display locales in a single follow-up call.

On-device · KMP

Off-topic hints

ML Kit on Android and Apple Vision on iOS label the frame locally so a cat photo on a "fountain" theme gets a gentle warning before upload.

Speech · fallback chain

Voice messages

Voice notes are transcribed through a keyless path first and fall back to Whisper only when a key is set, so the feature needs no configuration.

Route by cost and stakes

Opus where the output is public or high-stakes, Haiku for volume, Batches for bulk. Model choice is an environment variable, not a rewrite.

Ground the prompt, guard the output

Personas per category, EXIF and theme context in every call, and an explicit rule to describe only what is unmistakably visible.

Work AI-natively

Claude Code is the daily driver, under a 1,000-line CLAUDE.md contract and 18 decision-record docs. Conventions are enforced by scripts, and an LLM-driven SAST pass covered 14 vulnerability classes.
